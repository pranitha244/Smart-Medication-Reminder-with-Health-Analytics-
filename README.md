# Smart-Medication-Reminder-with-Health-Analytics-
The Smart Medication Reminder with Healthcare Analytics is a machine learning–based web application designed to predict medication adherence and provide intelligent reminders to patients. 
The system analyzes patient data such as age, gender, chronic condition, medication type, dosage, and reminder status to determine the likelihood of missing medication.
Based on the prediction results, the system classifies patients into High Risk, Moderate Risk, or Low Risk categories and generates appropriate alerts. It also provides visual analytics to help understand adherence patterns and support better healthcare decision-making.

 **Features**
Predicts medication adherence using machine learning
Classifies patients into risk levels (High / Moderate / Low)
Generates smart reminders and alerts
Displays healthcare analytics through visualization
User-friendly web interface using Flask
Fast and accurate prediction system
